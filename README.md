# Kasuslabor · 德语四格实验室

Kasuslabor 是一个适合德语初学者自学和复习四个格的双语网站。它不要求登录，也不连接云端；语言设置、学习进度和收藏都只保存在当前浏览器中。

## 网站里有什么

- 按顺序组织的 17 个学习单元，覆盖四格基础、动词和介词支配、词形变化以及完整句子。
- 中文与德语双语讲解，可随时切换为“中 + DE”“仅中文”或“Nur Deutsch”。
- 句子透视器、名词短语变形器、双向介词空间实验等互动工具。
- 独立的速查与复习页面，支持搜索、分类和本机收藏。
- 自动记录已经打开过的课程单元；目录中的“重置”只清除学习进度，不会删除收藏或语言设置。

## 运行方法

需要安装 Node.js 和 npm。推荐使用当前的 Node.js LTS 版本。

第一次运行时，在本目录打开终端：

```bash
npm install
npm run dev
```

终端会显示一个本地地址，通常是 `http://localhost:5173/`，在浏览器打开即可。

以后如果 `node_modules` 目录仍然存在，只需执行：

```bash
npm run dev
```

按 `Ctrl+C` 可以关闭本地网站。

## 数据与隐私

网站不会创建账号，也不会上传学习数据。以下内容保存在当前浏览器的本地存储中：

- 讲解语言设置；
- 已打开的课程单元；
- 速查页收藏。

清除浏览器的网站数据会同时清除这些记录。
